N4 文法重點核心
助詞 — は / が / を / に / で / へ の差異
て形 — ている / てから / てもいい / てはいけない
條件形 — たら / ば / と / なら 的差異
意志・願望 — たい / てほしい / てみる / つもり

撲克桌建議：每次去之前準備 3 句。例：「今日は運がいいね」「あのカードは強すぎる」
